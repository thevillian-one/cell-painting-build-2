# Stage 1B decisions

All decisions here precede calculation/inspection of candidate external treatment performance. Current authorization is Stage 1B only, overriding the historical planning-only status in the unchanged version 3 plan for this stage alone.

D01. Preserve frozen pilot annotation and stable sample identities, not current chemical revisions or display-name deduplication. Record all 125 key conflicts rather than silently reconcile them.
D02. Use the published pilot methods for 5 micromolar applied dose and baseline 1,000 seeded cells. Do not turn a source-library concentration into an assay dose. DMSO controls require explicit control/negcon annotations.
D03. Accept pilot only for bounded reference/within-experiment work, report fixed-coordinate confounding and one experiment/batch. Count eligible pairs without computing phenotype scores.
D04. Tag eight image-channel token types and technical feature families before defining a final fluorescence endpoint. This audit does not fit or execute feature selection.
D05. Curate only original fluorescent field references; remove duplicate mappings and calibration-image references. Preserve two missing site records; no image pixels were retrieved.
D06. Select Stain5 Thermo Standard development candidates and separate Reagent1 Thermo batch/site candidates from metadata. Keep PerkinElmer supplier variants and reimages out of their biological replicate groups. Reagent1 is not claimed to be a prospective temporal test.
D07. Select Stain4 2,000-cell Standard as a separate contextual candidate for comparison with scope, subject to dose/exposure checks. Do not mix this with the 1,000-cell condition.
D08. Match 82 public MOA sample IDs/chemical keys conservatively across sources. Retain Compound1-8 as anonymous source labels, not automatically confirmed cross-study chemicals. An initial overly restrictive assumption that all 90 were public BRD IDs failed and was corrected; logs preserve that event.
D09. Select one scope PE acquisition setting for P1-P4 and conservatively group repeated settings by P number. Leave physical preparation identities and treatment duration pending rather than guess.
D10. Use exact frozen S3 listings and Git trees for a bounded 15-profile follow-up, plus source metadata/pipelines and optional primary-methods XML. Git LFS pointers are not data. Record and verify each pointer/content hash.
D11. Stage 1B helper uses strict UTF-8-sig for normal tables and explicit CP1252 only for the known protocol master source. No universal Latin-1, replacement decoding, or ignored checksum errors.
D12. The additive update changes no Stage 0/1 files or their checksums. New checksums are generated from the delivered bytes, verified after a Windows-style Git line-ending roundtrip. This is not an actual Windows runtime certification.
D13. External profile checks export metadata/schema only; no treatment-value summaries, normalization or performance-based selection. Any embedded annotation/layout disagreement remains a qualification note and blocks cohort acceptance.
D14. Funding authorization remains zero. Run only public standard GitHub Actions with user-confirmed no paid overages, fixed time/transfer caps and no paid package install.
D15. Use repository-connected Codex for implementation/tests and ChatGPT for iterative scientific review as a workflow recommendation, not a substitute for evidence. Every agent receives the same plan, decision log, stage authorization and checkpoint. Do not claim manually authored work or independent review that did not occur.
