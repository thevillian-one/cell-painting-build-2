# Third-party sources and notices

The small reference layouts derive from public study metadata in the pinned `jump-cellpainting/pilot-data-public` and `jump-cellpainting/jump-scope` repositories. Their original metadata bytes, source hashes and repository license files are retained in `reference-data/originals`, `reference-data/provenance.json` and `reference-data/notices`. Original repository trees and S3 listing responses document target selection.

The CPJUMP1 pilot source revision is preserved in the parent Stage1A artifact along with its BSD-3-Clause code and CC0 data notices. The protocol author repository's license is retained with this update. Citations to the original experimental publications appear in the cohort-audit report. No upstream analysis script is executed by this acquisition tool and no whole paper or figure is redistributed in this update.

The newly written acquisition and audit scripts are project implementation, not the upstream CellProfiler/Pycytominer/copairs packages. Synthetic unit-test fixtures are explicitly labeled; the source designs and pilot audits use real public data. Final public-release code/data licensing and attribution remain part of Stage 8, and the license of a dataset is not a substitute for the license of reused code.
